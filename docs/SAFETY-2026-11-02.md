# Safety gates — 2026-11-02

**Audit: 2026-11-02. Final gate: 2026-11-06. Current tree: 2026-11-06.**

Target: `Fixture` public release, branch `public-v2`.
Channel: GitHub public repository.
What ships: code, docs, tests, benchmark cases, the two desk design cases
(`laptop-cradle`, `underdesk-shelf`), and a silent product reel (GIF)
generated from the real renders and measured numbers.
What does not ship: private development history, session memory, local reference
photos, the handheld keyboard design (source, exports, or render), and raw
benchmark captures.

## 1. Code safe

- No high-signal or noisy secrets in the public tree or its history.
- `.env` is untracked and ignored. `.env.example` contains empty placeholders
  only.
- Test fixture keys are synthetic (`sk-test`).
- No private keys, cloud credentials, or auth tokens found.

Evidence: `publish-ready` scanner, public-v2 clone:

```text
history_secrets: 0
history_noisy:   0
history_personal: 4  (intentional name/email/handle in AUTHORS, NOTICE,
                     package.xml, pyproject.toml)
sensitive_files_ever_added: .env.example (empty placeholder)
```

## 2. Artifacts safe

- 304 tracked files, ~3.4 MB.
- `designs/keyboard/` is absent from the tree, the branch history, and the
  product reel. Only `designs/desk-mounts/laptop-cradle/` and
  `designs/desk-mounts/underdesk-shelf/` ship.
- No private session state, local handoffs, agent notes, or reference photos.
- No absolute user home paths in tracked text.
- No private sibling repo names or local run records.
- STEP/STL headers are tool-generated; no author or path metadata.

## 3. Git history clear

- `public-v2` is a single initial commit (`Initial public release: Fixture
  v0.2.0`); no private development history is reachable from the branch.
- The private `main` history and the older `public-v1` snapshot are not
  ancestors of this branch.
- The removed keyboard designs are not recoverable from the public branch
  history and do not appear in the product reel.
- Commit author is the public maintainer identity.

## 4. Running instance safe

- Default bind is `127.0.0.1:8766`; no network exposure by default.
- The model emits named tool calls only. `python` actions are stripped; the
  harness has no shell/eval path.
- Cloud inference is opt-in. The default is local Ollama; no API key is
  required.
- Gate checks on the release tree:


## Known limits

- The manual GUI soak is still open; the Path B smokes run headless.
- Raw head-to-head captures are not published. The cases, scorer, method, and
  pinned competitor commit are.
- This is a solo project; the public name, email, and GitHub handle in
  `AUTHORS`, `NOTICE`, and package metadata are deliberate. Use a GitHub
  noreply address instead if that changes.
- KiCad is a proposal, not code.
- The README product reel is a silent reel, not a live screen recording. A live
  walkthrough is planned and is a separate asset. The reel contains no keyboard
  render, and no keyboard CAD ships.

## Go/no-go

- **Security:** go. No secret, private-file, or history blocker.
- **Design consent:** go for the two desk mounts; the keyboard design is excluded
  from the repo and the product reel.
- **Visibility:** hold - the public flip was rolled back for the roadmap/privacy
  audit; re-flip requires explicit owner approval.
