# Safety gates - 2026-11-01

> **Historical, pre-rename.** This evidence describes the `freeAICAD` tree,
> snapshotted before the `Fixture` rename; the branch carried the label
> `public-v1` at the time. Counts and gate ids here are historical. The current
> public tree is `public-v2`; see `docs/SAFETY-2026-11-02.md`.

Target: the `freeAICAD` pre-rename snapshot (branch label `public-v1` at the
time).
Channel: GitHub public repository.
What ships: code, docs, tests, benchmark cases, and the STEP/STL design examples.
Private session memory, handoff notes, local reference photos, and the private
development history do not ship.

## 1. Code safe

- No high-signal or noisy secrets across the public history or working tree.
- `.env` is untracked and ignored. `.env.example` contains empty placeholders
  only; the scanner flags the filename, not a value.
- The harness starts without credentials and reports the local Ollama lane.

## 2. Artifacts safe

- Private session state and local handoffs removed, along with local keyboard
  reference photos.
- No absolute user paths remain in tracked text files.
- The STEP/STL design exports are kept intentionally as public examples; they
  are reproducible from `designs/`.
- Public tree (historical count): 301 files, 4.8 MB tracked; no databases,
  logs, or secrets.

## 3. Git history clear

- The public branch starts at a single root commit (`Initial public release`)
  followed by release-preparation commits. Private development history is not
  published.
- A depth-1 clone of the public branch is the artifact that was scanned; no
  private history is reachable from it.
- The scanner found no secrets in the public history.

## 4. Running instance safe

- Default bind is `127.0.0.1:8766`; no network exposure by default.
- The model only emits named tool calls. `python` actions are stripped; the
  harness has no shell/eval path.
- Cloud inference is opt-in. The default is local Ollama; no API key is needed.
- The fast gate passes on the public tree:

## Known limits

- The scanner's `personal` hits are the public GitHub handle `kcpatt27` and the
  public maintainer email. Both are intentional.
- The harness is loopback-only by default. Setting `FIXTURE_HOST` to a
  non-loopback address is an explicit operator choice and should be paired with
  a firewall or reverse proxy.
- Raw benchmark captures are retained privately; the method, cases, scorer, and
  failure analysis are public.
