# Provenance

- 2026-07 to 2026-10: developed locally under the working name `freeAICAD`.
- 2026-11-01: first sanitized snapshot (`v0.1.0`) was briefly public by
  mistake, then returned to private the same day. It was not a release.
- 2026-11-02: renamed **Fixture** for the public tree. The rename covers the
  Python packages, client modules, environment variables, docs, and package
  metadata.
- Public tree excludes private session memory, machine-specific paths, local
  reference imagery, and the handheld keyboard design. The keyboard is not in
  the repository and not in the product reel. The two desk mounts
  (`designs/desk-mounts/laptop-cradle/` and
  `designs/desk-mounts/underdesk-shelf/`) are retained as public examples and
  are reproducible from `designs/desk-mounts/desk_mounts.py`.
